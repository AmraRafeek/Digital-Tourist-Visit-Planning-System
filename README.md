# Digital Tourist Visit Planning System

A PHP/MySQL web application based on the supplied ITE2953 project proposal and SRS.

## Stack
- HTML5 / CSS3 / JavaScript
- PHP
- MySQL
- XAMPP
- Git/GitHub
- Google Maps links

## Setup
1. Install XAMPP and start Apache + MySQL.
2. Copy this folder to `C:\xampp\htdocs\digital-tourist`.
3. Open phpMyAdmin: `http://localhost/phpmyadmin/`.
4. Import `database.sql`.
5. Open `http://localhost/digital-tourist/`.
6. Admin login: username `admin`, password `password`.
7. Change the admin password before any real deployment.

## Main functions
- Browse places
- Search and category filtering
- Place details
- Google Maps location/directions links
- Current-session one-day planner
- Admin login
- Add / edit / delete places
- Responsive layout

## Important
The supplied proposal provides names, categories, distances and short descriptions for the initial 10 places. Other fields are marked `Not specified` rather than inventing source data. Verify opening hours, fees, facilities, coordinates and other changing information before final submission.
